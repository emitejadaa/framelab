# M0 spike report (2026-09-23/24)

Eleven throwaway spikes validated the riskiest assumptions of the spec before building on them.
Full per-spike reports live in [`results/`](results/); reusable code lives in
[`artifacts/`](artifacts/). Machine: Arch Linux x86_64, i5-1235U (often capped at 1.3 GHz with turbo
off, and loaded by other spikes; a normal laptop is 2–3× faster), 7.5 GiB, Python 3.14.7, pandas 3.0.6,
matplotlib 3.11.2, pyarrow 25.0.1, Node 24.21, Chromium 152.

| Spike | Question | Verdict | Decision |
|---|---|---|---|
| S1 Glide grid | 5M rows, React 19, headers, menus, portals | **PASS** (with a 1-line patch) | Keep Glide Data Grid 6.0.4-alpha24 behind the adapter; ship the scroller patch |
| S2 JupyterLab widget | Render, CSS isolation, shortcuts | **PARTIAL** → fixed shortcuts in M0 | Keep anywidget; choose CSS isolation strategy at M2a start (spike S12) |
| S3 transport under load | UI latency while pandas runs | p95 **PASS**, worst case **FAIL** | Keep in-process compute thread + async UI; guard string aggregations; revisit in M8 |
| S4 window launcher | Close detection, token flow | **PASS** on Linux (headless + CI) | Chromium `--app` default on Linux; token file deleted after connect |
| S5 matplotlib preview | Render budget at 1–5M points | **PASS** with reductions | M4 for lines, 20k sample for scatter, quantised colour, fast PNG encoder |
| S6 pandas census | Can forms be auto-generated? | **PASS** (89.8 % params → concrete widget) | Auto-forms + ~60 overrides; numpydoc at build time only |
| S7 Arrow windows | Every dtype displayable, fast | **PASS** | Encoder v2 (cached per-column plan); flechette with BigInt/Decimal options |
| S8 caller names | Names across Pythons/hosts | **PASS** + 1 bug (fixed) | callee check + pipe receiver (committed in M0) |
| S9 sdist without Node | Install without a JS toolchain | **PASS** | `tests/test_packaging.py` (slow) guards it in CI |
| S10 React Flow DnD | Canvas drags to external targets | **PASS** | React Flow drag for nodes; own pointer DnD only for external sources |
| S11 copy semantics | `copy()` cost vs `copy(deep=False)` | **PASS** | Show `copy()`, execute `copy(deep=False)` (16× faster, ~15× less memory) |

## S1 — Glide Data Grid
- 2 grids × 5M × 30 with 20-bin header histograms: 0 long tasks (>50 ms) in 9/9 GPU runs; 0 console
  errors on React 19.3 (StrictMode); menus and the overlay editor mount inside `.fl-root`'s portal.
- Stock alpha24 stops ~774 rows before the end at fractional DPR (exact-equality edge check in
  `InfiniteScroller`). The patch in `artifacts/@glideapps__glide-data-grid@6.0.4-alpha24.patch` fixes it.
- **M3:** add the patch via pnpm `patchedDependencies`; regression test at DPR 1.5 with scrollbars
  (last row 4,999,999); pass the `.fl-root` portal via `portalElementRef`; `preventDefault()` in context
  menu callbacks; resolve CSS tokens to concrete colours before building Glide's theme (its colour parser
  uses a hidden div in `document.body`); pre-format display strings when decoding Arrow blocks.

## S2 — JupyterLab widget
- Renders in 0.54–0.70 s (warm kernel), 1.2–2.1 s cold (mostly `import pandas`); two widgets independent;
  0 console errors; framelab CSS does not leak into the notebook (1287 computed properties compared).
- JupyterLab context menu suppressed. **Shortcuts fired** (focus stayed on the cell) → fixed in M0:
  `.fl-root` is focusable and takes focus on pointerdown.
- **JupyterLab's unlayered CSS beats framelab's `@layer`ed reset/utilities inside the widget** (pre
  padding, code/button fonts). Shadow DOM fixed everything in a probe. → **Spike S12 at M2a start**:
  Shadow DOM (verify Glide, React Flow, Base UI, cmdk and Tailwind `@property` inside a shadow root) vs.
  `important` utilities + unlayered reset. Also: detect the JupyterLab/VS Code theme (not only the OS);
  own menus must `preventDefault()` the native context menu.
- Bundle travels in every widget's `comm_open` → minified in M0 (370 → 278 KB).
- Widget RPCs queue behind running cells → keep the spec's "kernel busy" indicator.

## S3 — transport under load
- Window requests: p50 13 ms / p95 15 ms idle, p95 ≤ 24 ms under load (all operations).
- Worst-case stalls: aggregations over string columns hold the GIL for the whole call — 13.4 s
  (pandas `str`) and 36.8 s (object dtype); `sort_values` 0.6 s.
- **Decision:** in-process compute thread (a subprocess engine would duplicate every root, >1 GB for
  5M×30); the browser stays responsive and data requests show skeletons/spinners; the "aggregation
  touches non-numeric columns" warning becomes a guard; re-measure in M8.

## S4 — launcher (and the token flow)
- Headless Chromium boots the real bundle through the redirect-file → cookie flow; close detected < 5 s
  (E2E #1, also green on GitHub's Ubuntu runner with `--no-sandbox` for CI only).
- Found and fixed: a 303 hop after a navigation started from `file://` is cross-site and drops the
  `SameSite=Strict` cookie → `/?token=` now serves the page directly and strips the token.
- Found and fixed: the browser-tab fallback left the token file on disk.
- Not tested locally: real (non-headless) windows on Windows/macOS → covered by unit tests; M8.

## S5 — matplotlib preview
- Empty figure draw ≈ 80 ms, `layout="constrained"` ≈ 200 ms (throttled CPU).
- Line + M4 (pixel-identical): 126–214 ms at 1M, 214–298 ms at 5M. Scatter: sample 20k → 141/258 ms
  (dpr 1/2) at 5M. Colour-mapped scatter raw: 28–38 s at 1M → never render raw.
- Custom PNG encoder (filter 0 + zlib 1 from `buffer_rgba()`) ≈ 2.5× faster than Pillow, same size.
- `plt.figure(fig)` adopts pyplot-free Figures → `res.figures` returns plain Figures.
- **Defaults:** M4 for line-like layers; random sample 20 000 for scatter; sample + colour quantisation
  for colour-mapped scatter; full data for hist/hexbin/boxplot/aggregated bars; cap preview DPR at 2;
  `rcParams.copy()` (never `dict(rcParams)`, it imports pyplot).

## S6 — pandas API census
- 2313 parameters across DataFrame, Series, GroupBy, windows, Resampler, Index, `.str/.dt/.cat`:
  89.8 % map to a concrete widget (98.3 % of named params); runtime-only (no numpydoc) 80.9 %.
- 36 named params unknown (17 names: `ax`, `tolerance`, `fill_method`, `na_value`…); 199 `*args/**kwargs`
  (122 hideable, 77 need editors: `assign`, named `agg`, `apply` args, `eval/query`…).
- Deprecation markers belong to parameters (e.g. `copy`), not members: check only the docstring text
  before the first numpydoc section.
- Mutators: `insert`, `pop`, `update`, `eval(inplace)`; `inplace=True` returns self or None
  inconsistently; `DataFrame.interpolate(inplace=True)` mutates then raises → never pass `inplace`.
- Top-level functions: curated table (only 6 of 12 annotate their first argument).
- **M1b:** add widget kinds `scalar` and `values`; store candidates/nullable/choices per param;
  prototype in `artifacts/pandas_census.py`.

## S7 — Arrow windows
- Every awkward dtype displayable (0 decode failures over 14 files). Realistic 1000-row windows encode
  in 3–7 ms, worst-case messy 50 columns 19 ms warm (30 ms first window); decode 0.3–0.7 ms warm.
- Plain `astype(str)` fallback is unusable (2.7 s per window) → bounded per-cell formatter.
- **M1a:** use `artifacts/arrow_encoder_v2.py` (cached per-column plan per node, positional field
  names + `framelab` JSON metadata); frontend decodes with `{useBigInt, useDecimalInt}` and a
  type-aware formatter; encode only the visible column range for wide frames.

## S8 — caller names and environment
- 560 runs (Python 3.11–3.14 × 10 contexts × 14 call shapes): 0 raised, 540 ideal, 20 graceful.
- Bug fixed in M0: C callers (`sorted(key=explore)`) and `df.pipe(explore)`.

## S10 — React Flow drag and drop
- Node drag, drops on external boxes/tabs (DOMRect hit-test, snap back), node-on-node combine
  (`getIntersectingNodes`) and sidebar→canvas pointer DnD all work at zoom 0.5/1/2 and DPR 1/1.5.
- **M2a:** disable `autoPanOnNodeDrag` while the pointer is outside the canvas and restore the viewport
  after external drops (else it drifts 23–180 px); render a ghost in the portal while outside the canvas.

## S11 — copy semantics
- 3M × 20: `v.copy()` 195 ms / +366 MB vs `v.copy(deep=False)` + assignment 12 ms / +24 MB; results
  identical, originals untouched in 23/23 checks → confirms the spec's "equivalent verified form".
